# Franssen & Associés — proposition de refonte

Site vitrine statique, responsive et sans dépendance pour Franssen & Associés SRL.

## Contenu
- Page d'accueil complète
- Services, approche, équipe, FAQ et contact
- Formulaire sans stockage serveur, ouvrant le client mail
- Mentions légales et confidentialité à faire valider avant mise en production officielle
- SEO de base, favicon et configuration Vercel

```bash
python3 -m http.server 8080
```
